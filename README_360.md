# ORA Space · 360 first celestial experience

**Companion ORA 360 service:** `akadaan310/ORA/service/oraspace360.py` and `service/ora360.py`.

Run `python3 -m service.oraspace360 --web ../ORASPACE/web` from the sibling ORA repository. Open the loopback URL from the same machine. HTML is an accessible overlay, not the underlying space simulation; painter lives in `web/scene.js`, layout lives in `web/style.css`, controllers live in `web/app.js`.

The scene is an interactive, original procedural interpretation of the user's approved mobile and desktop reference screenshots. It is not a sourced astronomical sky, fluid water physics, or a replacement for the final premium rendering milestone. No third-party photos or unlicensed assets are bundled. On mobile the bottom GLASS/ORA vessel awakens the same command field; desktop places the field under the main orbit. The canvas, orbital spheres, event-synchronized water, skyline, lamps and stateful artifact pane are all live code.

When connected, `app.js` uses real persistent ORA 360 API creation, artifact rendering, local approval, read-only Codex anchor and Baton offer. When disconnected, it displays *explicitly labeled local preview* and no network effects occur. `window.ORAScene.emit` shows a water ripple when a real page event happens, not fake CPU telemetry.

Validated on desktop `1440x900` and mobile `412x915` Chromium layouts with Playwright. Browser screenshots are in the downloadable review bundle, not source-controlled backgrounds. Real physical Android and production HTTPS tests remain required.
