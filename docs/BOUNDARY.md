# ORA Space repository boundary

This repository contains the consumer website, later PWA, Android and iOS clients, design system and front-end interaction contracts. It **does not** own the ORA compiler, permissions, provenance ledger, persistent service or worker runtime. Those belong in `ORA`, exposed through versioned HTTP/PURL/MCP adapters. Client builds may embed a compiled C++ core or a language-specific SDK, but must not secretly fork agent authorities.

Landing-page IA: ORA Sovereign center invitation; each orbiting ORA is a real named instance, whose operation/state reflects backend receipts. Every visible link or control can return focus to the center field instead of navigating to separate pages. A browser remains a browser underneath (HTTPS requests, security); don't simulate unavailable services.

Visual requirements (from approved conceptual screenshots): tranquil deep-blue sky with copper sunset over waterfront, clear glass input, softly active individual ORBs, low-frequency water perturbation associated with real interaction/mission transitions, less motion under `prefers-reduced-motion`. The startup here is a lightweight placeholder for exact design implementation; do not assert it equals the target screenshots.
